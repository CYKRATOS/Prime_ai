# Frontend Developer Intern Assignment Plan

## Goal
Build a Scalable Web App with Authentication & Dashboard using React (Frontend) and Node.js/Express (Backend).

## Core Requirements
1. **Frontend**: React.js/Next.js, Responsive (Tailwind), Forms validation, Protected Routes.
2. **Backend**: Lightweight Node.js/Express, Auth APIs (JWT), CRUD APIs, DB Connection (MongoDB).
3. **Features**: Register, Login, Dashboard, Task/Note CRUD, Security (Bcrypt, JWT).

## Execution Plan

### Day 1: Backend + Auth
- [ ] Setup Express Server
- [ ] Connect to MongoDB
- [ ] Create User Model
- [ ] Implement Register/Login APIs with JWT & Bcrypt

### Day 2: Frontend Core
- [ ] Setup React + Tailwind
- [ ] Create Login/Register Pages
- [ ] Implement Authentication Context & Protected Routes

### Day 3: CRUD + Polish
- [ ] Implement Task CRUD APIs (Backend)
- [ ] Build Dashboard UI (Frontend)
- [ ] Final Polish & Documentation
